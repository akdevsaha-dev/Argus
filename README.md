# Argus: Terminal-Native AI Engineering

Argus is a high-performance AI coding agent that runs directly in your terminal, built with **React/Ink** for a rich, interactive CLI experience. It bridges the gap between sophisticated LLM capabilities and local developer workflows.

### Why Argus stands out:
*   **Context-Aware Development:** Deeply integrated into the local file system, allowing for intelligent code navigation, file manipulation, and project-wide analysis.
*   **Production-Grade Architecture:** Built using **TypeScript** and **React**, leveraging a reactive CLI framework for a seamless, state-managed user interface.
*   **LLM-Powered Autonomy:** Utilizes Google’s latest Generative AI models via the `@google/genai` SDK to handle complex reasoning tasks, from debugging to feature implementation.
*   **Efficiency First:** Designed for developers who value keyboard-driven workflows—start coding instantly with `npm run dev` and exit effortlessly.

### Tech Stack
- **Engine:** Generative AI SDK (`@google/genai`)
- **CLI Framework:** React + Ink (Reactive, component-based CLI)
- **Language:** TypeScript
- **State Management:** React-based architecture

### Getting Started
1. Clone the repository.
2. Install dependencies: `npm install`.
3. Set your API key in `.env`.
4. Launch the agent: `npm run dev`.
